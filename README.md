Zingen é uma experiência de karaokê digital que combina entretenimento, tecnologia e performance vocal. O objetivo da plataforma é permitir que os usuários cantem suas músicas favoritas com qualidade, acompanhamento em tempo real e uma experiência visual moderna.

## ✨ Visão Geral

O projeto apresenta uma landing page para um aplicativo de karaokê com foco em:

- biblioteca ampla de músicas;
- remoção de voz por inteligência artificial;
- avaliação da afinação e performance vocal;
- gravação de performances;
- experiência gamificada para usuários;
- compartilhamento com a comunidade.

## 🎵 Funcionalidades

- Repertório de músicas para karaokê em ambiente digital;
- IA para remover a voz original e manter a melodia;
- Análise de afinação e pontuação da performance;
- Letras em tempo real durante a execução das músicas;
- Gravação de áudio e vídeo;
- Feed social para compartilhamento das performances;
- Planos e preços com opções para diferentes perfis de usuário.

## 🛠️ Stack Tecnológica

## 🚀 Como Executar

### Opção 1: abrir diretamente no navegador

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` em um navegador.

### Opção 2: usar um servidor local

No terminal, dentro da pasta do projeto, execute:

```bash
python -m http.server 8000
```

Em seguida, acesse:

```bash
http://localhost:8000
```
